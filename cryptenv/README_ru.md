# Cryptenv

`cryptenv` — это легковесный, безопасный и переиспользуемый Go-пакет для загрузки и управления чувствительными переменными окружения и секретами. Он гарантирует, что учетные данные никогда не сохраняются в открытом виде на диске или в оперативной памяти.

## Возможности

- **Безопасное хранение в RAM**: Все загруженные секреты хранятся в оперативной памяти в зашифрованном виде (AES-256-GCM). Расшифрование происходит "на лету" *только* в момент непосредственного запроса значения.
- **Чистый Go-дешифратор age**: Поддержка расшифрования файлов, зашифрованных с помощью **`age`** (как симметрично по мастер-паролю, так и асимметрично по ключам). Для работы **не требуются** сторонние бинарные утилиты (`gpg` или `age`) на сервере.
- **Гибкий парсинг структур**: Встроенный парсинг тегов `env` и `envDefault` (аналог библиотеки `caarlos0/env`).
- **Поддержка YAML**: Прямое десериализование YAML-строк из зашифрованных секретов в Go-структуры.
- **Интеграция со сторонними библиотеками**: Возможность экспорта секретов в обычную карту `map[string]string`.

## Установка

Добавьте пакет в файл `go.mod` или в рабочую область `go.work`:

```go
require github.com/nativebpm/connectors/cryptenv v0.0.0
```

## Использование

### 1. Инициализация

Инициализируйте безопасное окружение с помощью **Мастер-Ключа** (из него вычисляется хэш SHA-256, который используется как 32-байтный ключ шифрования AES):

```go
se, err := cryptenv.NewSecureEnv("my-master-password")
if err != nil {
    log.Fatalf("Ошибка инициализации secure env: %v", err)
}
```

### 2. Загрузка секретов, зашифрованных через age

#### Симметричное расшифрование (по паролю)
Расшифруйте и загрузите файл `.env.age`, зашифрованный симметрично:

```go
err = se.LoadAgeSymmetric("path/to/secrets.env.age", "my-master-password")
```

#### Асимметричное расшифрование (по ключам)
Расшифруйте и загрузите файл `.env.age`, зашифрованный с использованием публичного ключа сервера (или стандартного приватного SSH-ключа):

```go
identity, err := age.ParseX25519Identity("AGE-SECRET-KEY-...")
err = se.LoadAgeAsymmetric("path/to/secrets.env.age", identity)
```

### 3. Чтение секретов

#### Обычный запрос
Получите и расшифруйте значение секрета на лету:

```go
dbPass, err := se.Get("DB_PASSWORD")
if err != nil {
    log.Fatalf("Секрет не найден: %v", err)
}
```

#### Чтение со значением по умолчанию
```go
logLevel := se.GetDefault("LOG_LEVEL", "info")
```

## Парсинг структур (Декларативная конфигурация)

Вы можете заполнить поля Go-структуры напрямую, используя теги `env` и `envDefault`:

```go
type Config struct {
    DBUser   string `env:"DB_USER"`
    DBPass   string `env:"DB_PASSWORD"`
    DBPort   int    `env:"DB_PORT" envDefault:"5432"`
    SSLMode  bool   `env:"SSL_MODE"`
}

var cfg Config
err = se.Unmarshal(&cfg)
```

## Работа с YAML в секретах

Если вы храните целые структурированные блоки YAML внутри своих секретов, вы можете парсить их сразу в структуры:

```go
type DatabaseConfig struct {
    Host string `yaml:"host"`
    Port int    `yaml:"port"`
}

var dbCfg DatabaseConfig
err = se.GetYAML("DB_CONFIG_YAML", &dbCfg)
```

## Интеграция со сторонними библиотеками (например, `caarlos0/env`)

Вы можете получить расшифрованную карту `map[string]string` для интеграции с другими библиотеками парсинга настроек:

```go
import "github.com/caarlos0/env/v11"

envMap, err := se.ToMap()
if err == nil {
    env.ParseWithOptions(&cfg, env.Options{Environment: envMap})
}
```
