# Connectors

Go workspace with HTTP client utilities and service integrations.

## Modules

### [httpclient](httpclient)

Stream‑first HTTP client for Go. Efficient multipart uploads via `io.Pipe` with composable middleware.

```bash
go get github.com/nativebpm/connectors/httpclient
```

[Documentation →](httpclient/README.md)

### [gotenberg](gotenberg)

Go client for [Gotenberg](https://gotenberg.dev/) document conversion service. Convert URLs, HTML, Office documents to PDF with webhook support.

```bash
go get github.com/nativebpm/connectors/gotenberg
```

[Documentation →](gotenberg/README.md)
